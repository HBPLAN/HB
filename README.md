# HB Planner Professional

기존 파일을 이어붙이지 않고 저장 구조부터 새로 만든 버전입니다.

## 핵심 기능
- 날짜별 우선업무 저장
- 진행상태 및 A1~C3 우선순위
- 우선순위 정렬
- 10개 체크리스트 및 주간·월간 통계
- 오늘의 메모, 업무 메모, 회고
- 일정 관리
- 미완료 업무 이월
- 검색
- TXT 저장
- JSON 백업/복원
- PWA 홈 화면 설치

## GitHub Pages 업로드
압축을 푼 뒤 내부 파일과 폴더 전체를 저장소 최상단에 올리세요.

필수 파일:
- index.html
- css/style.css
- js/storage.js
- js/data.js
- js/app.js
- manifest.webmanifest
- service-worker.js

업로드 후 Pages 설정에서 main / root를 선택하세요.


## 간단 로그인 기능

- 아이디와 비밀번호 입력
- 처음 입력한 아이디는 해당 비밀번호로 자동 등록
- 로그인 상태 유지 선택 가능
- 로그아웃 가능
- 사용자별 데이터 분리 저장

주의: 이 로그인은 개인용 브라우저 안에서만 작동하는 간단 로그인입니다.
비밀번호는 브라우저 저장소에 보관되므로 강력한 보안이 필요한 용도로 사용하지 마세요.
PC와 스마트폰 데이터 자동 동기화 기능은 포함되지 않았습니다.
