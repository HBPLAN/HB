# HB Planner Professional

기존 파일을 이어붙이지 않고 저장 구조부터 새로 만든 버전입니다.

## 핵심 기능
- 날짜별 우선업무 저장
- 진행상태 및 A1~C3 우선순위
- 우선순위 정렬
- 10개 체크리스트 및 주간·월간 통계
- 오늘의 메모, 업무 메모, 회고
- 일정 관리
- 미완료 업무 이월
- 검색
- TXT 저장
- JSON 백업/복원
- PWA 홈 화면 설치

## 간단 로그인 기능

- 아이디와 비밀번호 입력
- 처음 입력한 아이디는 해당 비밀번호로 자동 등록
- 로그인 상태 유지 선택 가능
- 로그아웃 가능
- 사용자별 데이터 분리 저장

주의: 이 로그인은 개인용 브라우저 안에서만 작동하는 간단 로그인입니다.
비밀번호는 브라우저 저장소에 보관되므로 강력한 보안이 필요한 용도로 사용하지 마세요.
PC와 스마트폰 데이터 자동 동기화 기능은 포함되지 않았습니다.


## V1.2 저장 안정화

- 로그인 상태 유지 기본 활성화
- 마지막 로그인 아이디 기억
- 사용자별 저장 키 고정
- 이전 Professional/V1 사용자 데이터 자동 이전
- 저장 직후 localStorage 기록 검증
- Safari/PWA 종료·백그라운드 이동 시 강제 저장
- 뒤로가기 캐시 복귀 시 데이터 재로딩

같은 기기의 같은 실행 환경에서 사용해야 합니다.
Safari에서 접속한 페이지와 홈 화면에 추가한 웹앱은 기기·iOS 버전에 따라
저장 공간이 분리될 수 있으므로 한쪽 방식으로 계속 사용하는 것을 권장합니다.
